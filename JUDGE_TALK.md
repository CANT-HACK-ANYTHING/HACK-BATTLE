## Answers

**Is this an LLM?**  
No. Head is written rules plus reading the picture. No ChatGPT. No Ollama in the lock.

**Does data leave the machine?**  
No. Picture goes into Wayne’s folder on this disk. Head ALLOW → picture deleted, hash kept. Head VETO → tombstone so we do not try that harm again.

**Why three processes?**  
So the thing that clicks cannot mark its own homework. The thing that refuses cannot move the mouse.

**What if the button moves?**  
Brain looks at the live window tree and rebinds. Head stays asleep.

**What if the number is wrong?**  
Head OCRs the packet Brain copied. If over ₹5,000 or pixels ≠ file → VETO. Brain freezes the mouse.

**Can this do hospital / bank?**  
Same pattern. Not this weekend. Tonight it is a clerk on one machine.

**Did you copy a GitHub agent?**  
No. This is our clerk, our window, our rules.

**Who built what?**  
BE1 Hands (click/type). BE2 Brain/wire/vault. BE3 Head/terminate.

**What if internet is off?**  
That is the point. Demo with Wi-Fi off.
